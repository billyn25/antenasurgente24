# Antenista Urgente 24 Horas

Web nueva de servicio técnico de antenas, porteros automáticos y videoporteros, con las tres áreas de igual importancia y atención urgente 24 h sujeta a disponibilidad.

## Estado
Fase 1: base de diseño, arquitectura SEO y auditoría. **No publicar para indexación hasta confirmar dominio, números por zona y censo completo de municipios.**

## Objetivos
- Páginas por municipio: antenista, reparación de porteros, instalación de videoporteros.
- Directorios por provincia, enlazado HTML, sitemaps, canonicals y schema de servicio.
- Diseño sobrio y llamativo, responsive, galería de trabajos reales, marcas, testimonios reales y CTA.
- Teléfono nuevo pendiente para Madrid, Guadalajara, Toledo y Cuenca. Resto: 641 589 394.
- Sin inventar oficinas, valoraciones, trabajos realizados o plazos de llegada.

## Desarrollo
`npm run build` genera `dist/` (preparación noindex).
`npm run audit` verifica la salida.
